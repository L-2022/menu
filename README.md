# 🍁 Menu – Digital Restaurant Menu

**Menu** — це цифрове меню ресторану, створене на React з використанням Vite, CSS Modules і Tailwind CSS. Проєкт орієнтований на канадську кухню, включає фільтрацію категорій, лічильники для страв, інформацію про поживну цінність та оптимізований для перегляду з мобільного через QR-код.

## 🚀 Технології

- **React 18**
- **Vite**
- **CSS Modules**
- **Tailwind CSS**
- **Redux Toolkit**
- **React Router**
- **Mantine UI**
- **React Icons**
- **Helmet Async**
- **Dompurify** – для безпечного рендерингу HTML
